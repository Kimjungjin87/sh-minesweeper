# SH지뢰찾기 — 웹앱(PWA)

광고·결제·로그인이 하나도 없습니다. 아이폰 Safari에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
Apple 개발자 등록도, 7일 제한도 없습니다. 한 번 열고 나면 비행기 모드에서도 열립니다.

## 1. 주소

GitHub Pages 로 올라가 있다: **https://kimjungjin87.github.io/sh-minesweeper/**

업데이트는 이 저장소의 `main` 에 고친 파일을 올리기만 하면 끝이다.
1~2분 뒤 GitHub 이 사이트를 다시 만들고, 아이폰은 **다음에 앱을 열 때 자동으로** 새 버전을 받는다.
(인터넷이 되면 늘 새 파일을 받고, 안 되면 기기에 담아 둔 파일로 연다. 게임 기록은 업데이트와 무관하게 남는다.)

## 2. 여자친구 아이폰에서

1. **Safari**로 주소를 연다 (카톡 안의 브라우저 말고 Safari)
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → 추가
3. 이제부터는 **홈 화면 아이콘으로만** 연다

> ⚠️ Safari 탭과 홈 화면 아이콘은 저장 공간이 **따로**입니다. Safari 탭에서 하던 기록은 홈 화면 앱으로 넘어가지 않으니, 처음부터 아이콘으로 시작하세요.

## 3. 저장 — 어떻게 지켜지나

| | |
| --- | --- |
| 자동 저장 | **한 수마다** 저장 (0.3초 모아서). 앱을 닫거나 다른 앱으로 넘어가는 순간에도 한 번 더 |
| 두 군데 보관 | 기기 안 IndexedDB 와 localStorage 에 같은 내용을 같이 쓴다. 한쪽이 비거나 깨져도 다른 쪽에서 살린다 |
| 지우지 말라고 요청 | 브라우저에 "이 저장소는 지우지 마" (persistent storage) 를 요청한다 |
| 그대로 복원되는 것 | 열린 칸·깃발·구역·보석·실수·화면 위치와 확대·**되돌리기 기록**·지뢰를 밟은 상태까지 |
| 백업 파일 | 설정 → **백업 파일 내보내기** → 파일 앱/카톡/메일로 저장. 앱을 지우거나 폰을 바꿔도 **불러오기**로 이어서 |
| 용량 | 다 푼 구역은 "다 풀렸다"만 적고, 칸은 불러올 때 다시 계산한다. 구역 10개 ≈ 15KB |

**기록이 사라지는 경우는 하나뿐입니다 — 홈 화면 아이콘을 삭제할 때.** 그 전에 백업 파일을 한 번 내보내 두면 됩니다.

## 4. 게임 내용

- 8×8 구역이 끝없이 이어지는 보드. 구역의 안전한 칸을 다 열면 구역 완성 🧩
- 보드 6종: 들판 산책(13%) · 오솔길(16%) · 깊은 숲(19%) · 심연(22%) · 오늘의 보드(매일 새 지도) · 타임 어택(3분, 구역마다 +20초)
- 💎 보석과 드문 💖 하트(보석 5개)를 모아 테마 5종을 연다
- **🖼 구역 그림** — 구역을 다 풀면 그 8×8 칸이 픽셀 그림(스마일·하트·고양이 등 19종, 드문 이니셜 S·H 포함)으로 바뀐다. 처음 찾은 그림은 홈의 **그림 도감**에 모인다. 그림 목록은 `pictures.js`
- **🔍 돋보기** — 구역을 하나 완성할 때마다 1개 (같은 구역은 한 번만). 돋보기 버튼 → 칸을 누르면 그 칸 둘레 3×3의 지뢰가 **5초간** 비쳐 보인다. 가진 수만큼 쓸 수 있고 모든 보드에서 같이 쓴다
- 지뢰를 밟으면 **실수로 따로 센다**(보드별 + 전체, 되돌려도 줄지 않음) → **되돌리기** 또는 **깃발 꽂고 계속**. 광고 없음
- 탭 = 파기, 길게 누르기 = 깃발 (아래 버튼으로 바꿀 수 있음), 숫자 칸 탭 = 주변 한 번에 열기, 끌기 = 이동, 두 손가락 = 확대
- 소리·진동 켜고 끄기 (진동은 iOS 18 이상 Safari에서 동작)

## 5. 고치고 싶을 때

| 바꿀 것 | 파일 · 위치 |
| --- | --- |
| 처음 뜨는 선물 메시지 | `app.js` 맨 위 `GIFT` |
| 보드 종류·지뢰 비율·타임 어택 시간 | `engine.js` 의 `WORLDS` |
| 보석·하트 확률 | `engine.js` 의 `gem()` (구역의 32%, 그중 4% 하트) |
| 돋보기 보이는 시간 | `app.js` 의 `PEEK_MS` (지금 5000 = 5초) |
| 테마 색·가격 | `app.js` 의 `THEMES` |

고친 파일을 `main` 에 올리면 그걸로 끝이다. 버전 번호를 따로 올릴 필요는 없다.
테스트: `node tests/engine.test.js` (규칙) · `node tests/browser.test.js http://localhost:8765/ <스크린샷폴더>` (브라우저, playwright 필요)

## 파일

```
index.html            화면 틀과 스타일
engine.js             게임 규칙 (지뢰는 씨앗+좌표 해시 → 무한 보드라도 저장은 연 칸만큼)
storage.js            저장 (IndexedDB + localStorage 이중 보관, 백업 내보내기/불러오기)
app.js                화면·손가락 조작·그리기·소리
sw.js                 오프라인용 서비스워커
manifest.webmanifest  홈 화면 앱 정보
icons/                아이콘
```
