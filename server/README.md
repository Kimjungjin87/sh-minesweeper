# 하드코어 랭킹 서버 만들기 (무료 · 약 5분)

서버비 없이 **Google 스프레드시트 + Apps Script** 로 돌아갑니다. Google 계정 하나면 됩니다.
기록은 그 스프레드시트에 한 줄씩 쌓이고, 언제든 열어서 직접 보고 고칠 수 있습니다.

## 1. 스프레드시트 만들기
1. https://sheets.new 를 열어 새 스프레드시트를 만든다 (이름 예: `SH지뢰찾기 랭킹`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다

## 2. 코드 붙여 넣기
1. 열린 편집기의 `Code.gs` 내용을 **전부 지우고**
2. 이 저장소의 **`server/Code.gs` 내용 전체**를 붙여 넣는다
3. 💾 저장 (Ctrl/⌘ + S)

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 검토 → 본인 계정 선택
   - "Google에서 확인하지 않은 앱" 이 뜨면 **고급 → (프로젝트 이름)(으)로 이동** → 허용
     (내가 만든 스크립트가 내 스프레드시트에 쓰겠다는 뜻이라 괜찮습니다)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사

## 4. 앱에 연결
`config.js` 의 `window.RANK_URL = '';` 따옴표 안에 그 주소를 넣고 올리면 끝입니다.
(Claude 에게 주소만 알려 주면 대신 넣어 올립니다.)

## 알아 둘 것
- **코드를 고쳐 다시 배포할 때**는 *배포 → 배포 관리 → ✏️ → 버전: 새 버전* 으로 하면 주소가 그대로 유지됩니다.
  "새 배포"를 다시 누르면 주소가 바뀌어 `config.js` 도 바꿔야 합니다.
- 시트 `scores` 의 줄을 지우면 그 기록이 랭킹에서 빠집니다 (부정 기록 정리용).
- 무료 한도(하루 수만 번 호출)는 지인끼리 쓰기에 충분합니다.
- 서버가 막는 것: 지난 회차 기록(초기화 후 6시간까지만 받음), 100%가 아닌 '완성', 사람이 낼 수 없는 속도, 이상한 값.
  다만 앱 코드가 공개돼 있어 마음먹고 조작하는 것까지 완전히 막지는 못합니다 — 지인용 랭킹으로 생각해 주세요.
